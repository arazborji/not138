# وب‌سایت دفتر اسناد رسمی ۱۳۸ تبریز

وب‌سایت ایستا، فارسی و راست‌چین، مناسب GitHub Pages.

## انتشار روی GitHub Pages
1. یک مخزن جدید در GitHub بسازید.
2. تمام فایل‌ها و پوشه‌های این پروژه را در ریشه مخزن بارگذاری کنید.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
6. پس از پایان انتشار، نشانی Pages در همان بخش نمایش داده می‌شود.

## اتصال دامنه notary138.ir
پس از خرید دامنه، در Settings → Pages دامنه را در Custom domain وارد کنید. سپس رکوردهای DNS را مطابق دستورالعمل روز GitHub Pages در پنل ثبت‌کننده دامنه تنظیم کنید. برای فعال شدن HTTPS گزینه Enforce HTTPS را پس از آماده‌شدن گواهی فعال کنید.

## افزودن فرم‌ها
1. فایل‌ها را داخل پوشه `forms/` بگذارید.
2. فایل `forms.js` را باز کنید.
3. نمونه موجود در ابتدای فایل را برای هر فرم در آرایه `formItems` اضافه کنید. مثال:
   `{ title: "فرم درخواست", description: "توضیح کوتاه", file: "forms/request.pdf" }`

## نکات مهم
- لوگوی ارسالی دفتر در `assets/logo.png` قرار داده شده و رنگ آن به رنگ اصلی سایت (`#3826de`) تغییر یافته است.
- محاسبه‌گر در این نسخه مبلغ ساختگی اعلام نمی‌کند. برای فعال‌سازی محاسبه عددی باید جدول رسمی تعرفه ۱۴۰۵ و منطق محاسباتی تأییدشده دفتر در `script.js` پیاده‌سازی شود.
- مدارک درج‌شده چک‌لیست راهنمای عمومی هستند؛ بسته به پرونده، قانون و استعلام‌های جاری ممکن است مدارک دیگری لازم باشد.
- لینک‌های پیام‌رسان بر اساس شماره همراه ساخته شده‌اند؛ بعضی پیام‌رسان‌ها برای شماره تلفن، لینک عمومی یکسانی ندارند و ممکن است لازم باشد شناسه/لینک واقعی حساب دفتر در `script.js` جایگزین شود.
- GitHub Pages سرویس میزبانی ایستا است؛ فرم دریافت و ذخیره امن مدارک در سرور در این نسخه وجود ندارد.
